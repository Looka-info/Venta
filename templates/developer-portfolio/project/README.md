# 💻 Developer Portfolio Template for VentaNext

An interactive portfolio and blog for systems programmers, backend architects, and software engineers. Built **100% in pure Venta** with terminal-aesthetic design tokens and zero-GC performance.

## ✨ Highlights
- **Interactive Terminal Shell**: Hero bio with monospace code simulation and command prompt styling.
- **Project Showcase**: Rich cards with GitHub badges, benchmark statistics, and live demo links.
- **Engineering Blog**: Multi-post blog architecture with reading time indicators and tag badges.
- **Contact API**: Built-in `/api/contact` endpoint for inquiry submissions.
- **Responsive Terminal UI**: Seamlessly adapts from desktop wide monitors to mobile smartphones.

## 🚀 Getting Started
```bash
# Start development server
vanta run main.va --port 3000

# Compile to native binary
vantac main.va -o portfolio && ./portfolio
```
