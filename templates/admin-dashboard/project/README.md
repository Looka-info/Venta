# 📊 Admin Dashboard Template for VentaNext

An enterprise-grade control panel, infrastructure telemetry monitor, and multi-tenant management platform built **100% in pure Venta** with VentaNext App Router.

## ✨ Highlights
- **Persistent Sidebar Layout**: Ergonomic shell with collapsibility, active route pills, and system breadcrumbs.
- **KPI Metric Tiles**: Live health indicators (throughput, p99 latency, active workers, error rates).
- **Data Tables**: Formatted user directory and cluster node tables with status badges and action controls.
- **Cluster Diagnostics API**: Direct integration with `/api/metrics` and `/api/users`.
- **Zero-GC Real-Time Monitoring**: Handles constant telemetry polling without UI micro-stutters.
