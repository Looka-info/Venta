# 📚 Documentation Website Template for VentaNext

A modern documentation and reference platform built **100% in pure Venta** with VentaNext.

## ✨ Highlights
- **Two-Column Documentation Layout**: Sticky left sidebar with nested navigation and table of contents.
- **Syntax-Highlighted Code Blocks**: Pre-formatted monospace code sections with copy buttons and language badges.
- **Technical Callouts & Admonitions**: Informative callouts for tips, notes, warnings, and performance insights.
- **Search API**: Built-in `/api/search` endpoint for instant documentation querying.
- **Zero-Dependency Native Static Export**: Prerender to static HTML/CSS files or serve dynamically with SSR.
