Venta compiles to a standalone native executable across Linux, Windows, and macOS with a toolchain written in Rust and in Venta itself.

0.24stypical compile

About 8x faster than rustc at -O3 on the same workloads (1.91 s), and close to GCC (0.28 s).

22 KBnative ELF

Standalone binaries around 22.5 KB, against roughly 11.8 MB for a Rust release build.

Safewithout a GC

Affine ownership, moves, and lexical borrow checking catch use-after-free and data races at compile time.

14optimizer passes

Inlining, SROA, GVN, SCCP, LICM, loop unrolling, tail-call optimization, and trace-based block layout, each switchable from the CLI.

JSONdiagnostics

Pass --json to check, compile, or run and get machine-readable errors for editors, CI, and AI pair programmers.

Mistakes fail at compile time.

Move a value, then touch it, and Venta stops the build with error E0301.

All of it is checked before a binary exists, with zero runtime overhead and no garbage collector.

struct Buffer { capacity: i64, size: i64 }
 
fn process_buffer(b: &Buffer) -> i64 {
    return b.size;
}
 
fn consume_buffer(b: Buffer) { }
 
fn main() -> i64 {
    let buf = Buffer { capacity: 1024, size: 42 };
    let s = process_buffer(&buf);   // borrow: buf still valid
    consume_buffer(buf);            // move: ownership transferred
    consume_buffer(buf);            // E0301: use of moved value
    return s;
}

Fourteen passes, one sweep.

InliningSmall and leaf callees fold into callers.
SROASplits stack aggregates into scalars.
GVN / CSERemoves repeated computations.
SCCPPropagates constants through branches.
LICMHoists loop-invariant work out of loops.
IVOCanonicalizes induction variables.
LSRTurns costly operations into recurrences.
Loop peelingSplits off the first iterations.
Loop unrollingRepeats loop bodies 2x or 4x.
Global DCEDrops code that nothing uses.
SchedulingReorders instructions by latency.
TCOSelf tail calls become loops.
Branch inversionFavors fall-through jumps.
Trace layoutOrders blocks for the cache.
Verify inChecks MIR invariants before optimizing.
Verify outRe-checks the MIR after optimizing.

Every pass can be turned off from the CLI, for example --no-licm or --unroll-factor=4.
